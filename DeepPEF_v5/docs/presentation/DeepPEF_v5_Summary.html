1. The core idea (biology)

Full detail →

Protein stability = folding free energy. The model computes two energies from the same backbone coordinates and subtracts them:

dG = Eunfolded − Efolded    ddG = dGmut − dGwt

Folded graph = real 3D contacts (all pairwise distances). Unfolded graph = same coords but reduced to the linear backbone chain (a random-coil reference). The difference is the model's reward for forming 3D contacts. A mutation keeps the coordinates fixed but changes the sequence one-hot + PLM embedding, so ddG isolates the sequence-driven stability change.

2. The dimension contract

Full detail →

Every tensor width derives from one config object (model_cfg_v5.CFG) read by both the graph builder and the model. Node feature layout:

[ D(16 distance) | Fb(32 bonded) | (burial b) | emb(E=1024 ProtT5) | one_hot(20) ]

one_hot always stays last (sliced from the right). Because widths come from one source, every lever's default reproduces the baseline tensors bit-for-bit.

3. The two-tower architecture

Full detail →

Two GNN towers run in parallel, are concatenated, re-joined with the raw PLM embedding, passed through light attention, and mapped to a per-residue energy that is summed:

StageWidth (baseline)
GCN input [dist|bonded|aa]52 → internal 36
GAT input [dist|aa]36 → internal 36
concat(GCN,GAT)36 + 36 = 72
+ raw emb72 + 1024 = 1096 (= fc_in_dim)
fc1 → fc21096 → 128 → K (K=1 scalar)
energyE = Σ per-residue (extensive; ÷L if length_norm)

GCN uses sequential backbone edges (i, i+1); GATv2 uses spatial k-NN / distance-cutoff edges.

5. Evaluation metrics

Full detail →
  • PCC (primary) r = cov(p,y)/(σ_pσ_y) — linear trend, shift/scale-invariant. Historical best ~0.5259.
  • Spearman ρ — Pearson on ranks; monotonic ordering, outlier-robust.
  • RMSE sqrt(mean((p−y)²)) — absolute error (diagnostic; energy is relative units).

6. Loss functions

Full detail →

loss = primary + reg + energy_reg + rank + corr (+ denoise, Lever E)

  • Huber(δ=1) — MSE near zero, L1 far out; robust to noisy labels.
  • Margin ranking max(0, −s·Δp + margin) — optimizes pairwise order (weight 0.1).
  • Energy reg 0.001·mean(E²) — anchors the extensive energy scale.
  • Pearson loss 1−r; CCC loss 1−CCC — CCC also penalizes shift + scale (agreement about the 1:1 line).
  • Denoise MSE (Lever E) — consistency under structural noise.

7. Dataset biology

Full detail →
  • Tsuboyama et al. 2023 mega-scale dataset (~hundreds of thousands of domains/mutants).
  • K50 cDNA-display proteolysis assay — folded proteins resist protease; K50 = protease concentration at the cleavage midpoint; converted to folding free energy dG. Higher K50 = more stable.
  • Clamp dG to [−1, 5] kcal/mol (--dg_ml) — the assay's dynamic range; outside it, values are extrapolations.
  • Single mutations + PNAS curation (--one_mut) — quality > quantity; adding unfiltered data hurt performance.
  • ThermoMPNN (ProteinMPNN inverse-folding competitor) proteins + homologs are held out to prevent test leakage.

8. EBM pretraining theory

Full detail →
  • Native = energy minimum: train the energy landscape so the native folded state is lowest.
  • InfoNCE / Boltzmann contrastive: L = E_native/τ + log Σ exp(−E_k/τ); negatives = decoy sequence, decoy structure, unfolded, cyclic permutations.
  • Denoising Score Matching (DSM): teach the gradient to point back to native under noise (v·∇E ≈ v·(−noise/σ²), finite-difference estimate).
  • Connection to Lever E: DSM builds the force field; Lever E keeps it intact during ddG fine-tuning.

9. Why physics-grounded

Full detail →

The bet is architectural — build thermodynamics into the model:

  1. Folded−unfolded difference mirrors the thermodynamic cycle.
  2. Extensive (summed) energy is additive over residues (interpretable per-residue terms).
  3. Flory / unfolded reference makes the difference meaningful.

This shrinks the hypothesis space to physically plausible functions → better data efficiency, interpretability, and generalization. Trade-off: constraints may cap raw accuracy vs a purely data-driven, inverse-folding-pretrained competitor. That is the research question.

10. Verification & limitations

Full detail →
  • CPU smoke test runs baseline + each lever on synthetic data (no GPU, no real data).
  • Baseline regression: default flags ⇒ no denoise/edge params, fc2=(K=1), burial_dim=0, gcn_span=1.
  • Fail-fast checks name the offending lever on any width mismatch.
  • GPU ablation ladder measures PCC one lever at a time.

Limitations: no inverse-folding pretraining in baseline; fixed WT structure per protein; extensive energy confounds length; relative-unit energy (RMSE is diagnostic); glycine virtual-CB caveat; ESM-IF 1536-dim broadcast alignment relies on the CFG contract.
