# results/trajectory_runs.txt -- ALLOWLIST for runs with more than one scored TEST epoch.

# Read scripts/gate_epoch_selection.py first. Every run in this project is scored on the
# 28-protein test set exactly ONCE, at the epoch chosen by validation ddG PCC
# (Megascale-fineTuning/run_calib_eval.sh line 15). A run with several scored test epochs
# creates the opportunity to quote the best of them, which is test-set peeking. The two
# runs below have six scored epochs each for a legitimate reason, recorded here.
#
# THE CANONICAL EPOCH IS BINDING. It is the val-selected epoch -- argmax of the
# "ddG PCC=" lines in the training log, the same parse run_calib_eval.sh performs.
# Any table, abstract, or thesis sentence quoting one of these runs MUST quote the
# canonical epoch. The other scored epochs exist only to plot a trajectory.
#
# FORMAT (pipe-separated, one record per line):
#   <run_tag> | canonical=e<N> | <one-line reason>
#
